# Personal Portfolio
This website was created with [Create A React App](https://react.dev/learn/creating-a-react-app) framework and deployed using [Vercel](https://vercel.com/).

## About This websitexxzs
This website was created as a way for me to improve my skills in React and display useful information about myself including my skillsets and past projects I have worked on. In total, this project took me about a week or so to work on as I had some initial experience with React framework. The most challenging aspect of this I would say is the TailwindCSS because I was not familiar with a lot of its elements and had to refer to the documentation a lot. Overall, I have learned a lot about styling and typescript which React uses for its pages

## References
The majority of the code was written by me, but I had to refer to some outside sources as well. I referred to the documentation by Tailwind Plus to help with my knowledge of TailwindCSS. I also referenced and took inspiration from other sites, most notably W3School for help with typescript functions and side navigation bar, Stack overflow for help with the responsive design, and Dev.to for some of the animations.
